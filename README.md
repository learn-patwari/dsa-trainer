# dsa-trainer

`dsa-trainer` is an open-source project for self-training in Data Structures and Algorithms through problem-solving patterns.  
It is designed to run locally on your own machine/server (localhost), with no external hosting dependency.

## Features

1. **Blind Challenge**  
   Practice problems in a distraction-free mode to simulate real interview pressure.

2. **Pattern Identification**  
   Learn to recognize recurring DSA patterns and map problems to the right approach.

3. **LeetCode Tracking**  
   Track solved problems and monitor your progress across practice sessions.

4. **Target-Based Study Plan**  
   Build a study plan based on goals you want to achieve (for example, interview prep deadlines or topic completion targets).
